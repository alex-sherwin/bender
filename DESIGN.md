# Overview

Bender is a tool to streamline building LLM prompts.

The interesting thing Bender aims to provide is data management to consolidate many sources of highly contextual data which have semantic linkages.

It aims to expose an efficient, user friendly interface to build well structured LLM prompts filled semantically linked data.



# Why?

The quality of LLM outputs are generally garbage in, garbage out.

Providing specific, well structured and highly contextually relevant information greatly improves the results.

The issue is humans are busy (read: lazy).  At least I am.  I will write one or two well structured prompt and get good results, but quickly lose the discipline to spend more time writing prompts then code, which results in regressing to trivial prompts and getting generally poor quality results.

Bender aims to allow busy (lazy) developers like me to get great results from LLMs all the time.



# NIH?

The main goal of Bender is not to just be a prompt library/builder.

The interesting functionality is intended to come from the interface into contextual and semantic data in conjunction with basic prompt engineering techniques and best practices.
